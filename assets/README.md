# ShopVerse

GitHub-ready responsive e-commerce frontend.

## Files
- `index.html` — Home
- `shop.html` — Search, filters and sorting
- `product.html` — Dynamic product detail page
- `wishlist.html` — Working wishlist
- `cart.html` — Working cart and quantity controls
- `checkout.html` — Demo checkout
- `about.html` and `contact.html`
- `assets/style.css` — Main styling
- `assets/app.js` — Products and all shopping functionality

## GitHub Pages
Upload all files while keeping the folder structure unchanged. GitHub Pages can use `index.html` as the entry page.

> This is a frontend demo. Real orders, login, database and payments require a backend/API and a payment provider.
